# 0012 F/A-18E への差し替え

2026-09-18 決定。Phase 8。

## 決めたこと

自機を F/A-18C から F/A-18E スーパーホーネットへ差し替える。モデルは Sketchfab の KOG_THORNS 版（CC BY 4.0）。飛行モデルの諸元も E 型で取り直す。舵面は名前で拾えないので位置と寸法で同定する。

## モデルを選ぶ

6 件を測って 1 件に絞った。落とした理由はほとんどがライセンス。

| 候補 | ライセンス | 判断 |
|---|---|---|
| KOG_THORNS 版 | CC BY 4.0 | **採用。**220 部品、77,840 三角形 |
| 42manako 版（USA 塗装） | CC BY-NC 4.0 | 落とした |
| bohmerang 版 | CC BY-NC 4.0 | 落とした |
| FlightGear FGAddon | — | E 型が無い |
| NASA 3D Resources | 米国政府著作物 | 戦闘機が無い（0005 で記録済み） |
| Sketchfab の CC0 | CC0 | 戦闘機が無い |

**NC は GPL と両立しない。**NC は商用利用を禁じ、GPL は受け取った誰もが商用利用できることを保証する。同梱すると矛盾する。自分が商用利用するかどうかとは別の問題で、公開した時点で第三者に GPL の権利を渡すため。

見た目では 42manako 版の USA 塗装が希望に近かったが、この理由で採れなかった。zip を落とす前に `license.txt` を見れば分かる。

CC BY 4.0 は GPLv3 と一方向互換で、このリポジトリは GPLv2+（v2 or later）なので取り込める。表示義務は `assets/CREDITS.md` の記載で果たす。

## 舵面は幾何で同定する

C 型（FlightGear の AC3D）は `AileronLeft` のような名前で舵面が分かれていた。**この原本は違う。**Sketchfab が FBX から変換したので、ノード名は `Meshpart126_Material.001_0` のような自動生成名。

位置と寸法から当てる。当てた結果は `tests/tools/f18eParts.test.ts` が固定する。

**「左右対称の薄板が 1 件だけ当たる」では足りなかった。**主翼の外側は前縁フラップ（X 0.66）・パネル本体（X 1.43）・エルロン（X 2.47）の 3 枚に分かれていて、真ん中のパネルも条件を満たす。拾ったままロール指令を入れると外翼が翼端ごと 30 度傾き、翼の上に黒い板が浮いた。翼弦で見分ける。エルロンは 0.88 m、パネルは 1.99 m。

左右は原本に残った名前で決めた。`La1`（Left aileron）が Z +5.41、`Lw1`（left wing）が +4.58、`Rw1` が −4.58。3 つが揃って +Z を左と言う。**幾何だけで当てていると左右を取り違えても検査は通る**ので、この 3 つで符号を固定した。

ヒンジ軸は bbox から組む。C 型は FlightGear の XML が 2 点を持っていたが、こちらは何も付いていない。エルロンとラダーは前縁、スタビレータは全遊動なので翼弦の 30% に置く。

フラップは同定しない。`SurfaceChannel` が elevator / aileron / rudder の 3 つしかないので載せても指令が来ない。名前だけ付けて glb から外すと「なぜ載らないか」を毎回説明することになる。

## 飛行モデルを E 型で取り直す

見えている機体が E 型なら物理も E 型にする。0005 で C 型へ書き換えたときと同じ理由。

| 定数 | C 型 | E 型 |
|---|---|---|
| 質量 | 16,650 kg | 21,320 kg |
| 主翼面積 | 37.16 m² | 46.45 m² |
| 翼幅 | 11.43 m | 13.62 m |
| 最大推力 | 157,470 N | 195,720 N |
| 揚力傾斜 | 4.0 /rad | 4.19 /rad |
| 頭打ちの迎角 | 27.2° | 26.0° |

G 制限 7.5、迎角制限 35 度、有害抗力係数 0.026 は据え置き。E 型でも同じ値か、公表された値が無い。

翼面荷重 4,394 → 4,501 N/m²、推力重量比 0.96 → 0.936。どちらもわずかに不利な側へ動く。E 型が C 型より鈍いのは実機どおり。コーナー速度は 177 → 179 m/s とほとんど変わらない。

**この 2 つは公表値そのものと突き合わせられる。**翼面荷重を重力加速度で割ると 459.0 kg/m² で、諸元表の 459 と一致する。推力重量比は 44,000 lbf ÷ 47,000 lb = 0.9362 で、諸元表の 0.93 はその切り捨て。質量・翼面積・推力の 3 つが独立に裏を取れている。

## 当たり判定も取り直す

`AIRCRAFT_CAPSULES` は C 型の実測で組んであった。胴体カプセルは全長 14.48 m で、E 型の 17.33 m に対して機首側が 2.3 m 足りない。glb から測り直した。

| 値 | C 型 | E 型 |
|---|---|---|
| 機首 Z | −7.999 | −10.311 |
| 胴体の尾端 Z | 6.48 | 7.02 |
| 胴体の断面 | 幅 1.09 × 高 1.71 | 幅 2.62 × 高 1.72 |
| 主翼の半翼幅 | 5.52 | 6.594（翼端ランチャ込み） |
| 水平尾翼の半幅 | 3.43 | 3.542 |

胴体カプセルの半径は 0.9 のまま。C 型では高さで決めた値が幅に余っていたが、E 型では幅に足りない。双発ナセルと LEX まで覆うと、中心線から 1.3 m の円柱が全長 17 m にわたって伸びて実機より太くなる。

**これを忘れかけた。**飛行モデルだけ替えた時点でフレアの生存時間が「60 秒でも決着しない」に変わり、試験のほうを書き換えて辻褄を合わせるところだった。当たり判定の検査 24 件は C 型の外形と突き合わせていたので、全部通っていた。生存時間は当たり判定を直して 35.9 秒に戻った（C 型は 40.6 秒）。

## アフターバーナーは自前で描く

**原本に炎が無い。**F/A-18C（FlightGear）は `ExternalFlame` と `InternalFlame` という板を持つ。`src/render/aircraftView.ts` がそれをスロットルで出し入れしていた。Sketchfab のモデルには何も付いていないので、そのまま差し替えると既定の機体から炎が消える。

C 型の板を glb ごと移す道具（`glb-graft.mjs`）を書いて実測した。ノード・メッシュ・マテリアルはすべて移り、`getObjectByName` で取れる。bbox も正しい位置に出る。**それでも 1 画素も描かれなかった。**大きさを 4 倍にしても、機体の前方へ動かしても出ない。原因を追うより自前で描くほうが速く、色を作り込めるので道具ごと捨てた。

位置だけ glb の `extras.nozzles` から渡す。実測で左右のノズルが X ±0.5、Y 0.39、後端 Z 7.02、口径 0.3 m。

形は円錐を 2 層。内炎が通常合成で色を決め、外炎が加算合成で光を足す。**加算 1 枚では昼間に白く飛ぶ。**明るい地形や空を背景にすると足した色が飽和して、赤黄ではなく白い筋になる。

### 色は露出前の線形値で置く

最初 `(1.0, 0.88, 0.55)` と書いて実測したら、画素が `(249, 224, 192)` になった。`RenderPipeline` はトーンマップの中で露出 6 倍を掛ける。3 成分とも 1 を大きく越えるので、AgX が白へ寄せる。

露出後に赤だけが 1 を越える帯（露出前 0.26 前後）へ置き直した。ノズル直後の画素が (222, 150, 125) の橙になる。

## 見送ったもの

F 型（複座）は入れない。原本が E 型のみ。

C 型のモデルは残す。`?craft=f18` で描ける。ただし飛行モデルは E 型の諸元しか持たないので、絵を見比べる口であって手ざわりは比べられない。

ロール率は据え置いた。翼が 25% 大きいぶん実機では鈍るはずだが、公表された値が見つからない。**根拠のない数は動かさない。**
