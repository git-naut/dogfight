# 0022 HUD を録画の比率で描く

2026-10-15 決定。Phase 10 の段 B1。HUD の大きさと位置を、ユーザーの録画（ACE COMBAT 7 の講座、1920x1080・30fps・789 秒）で測った値に合わせた。録画は Phase 10 の原本で、測った値と測り方は `~/.claude/plans/dogfight-ac7-ref/measure/` にある。録画のコマはリポジトリに入れない。使うのは配置・大きさ・色の数だけ。

## 決めたこと

大きさは録画の 1920x1080 の画素で書き、縮尺 `scale = min(高さ/1080, 幅/1920)` を掛ける。位置は画面の割合で置く。横に長い画面でも文字は高さに合い、左右の要素は端に寄る。縦に長い画面でもはみ出さない（ユーザーの決定）。

以前は CSS の画素で固定していた。文字は 13px で、1920x1080 の画面では大文字が約 9.5 画素だった。録画は約 20 画素。表示倍率 150% の全画面（CSS で 1280x720）では約 14 画素になり、画面の大きさで見え方が変わっていた。

| 要素 | 録画（1920x1080 の画素） | 置いた値 |
|---|---|---|
| SPEED | 見出しと数字の箱の 2 段、x 611〜700・y 500〜557 | 箱の幅 100・高さ 35、照準側へ 12 尖らせる |
| ALT | x 1216〜1324・y 499〜557 | 同上 |
| レーダー | 枠 x 100〜399・y 724〜1025 | 一辺 300、左端と下端は画面の割合 |
| 兵装の一覧 | 見出し x 1656 から左揃え、数 x 1821 で右揃え、行の間隔 35 | 同じ。行は GUN・MSL・FLR・DMG の 4 行 |
| 自機の輪郭 | 一覧の下、中心 (1698, 955) | 同じ。大きさ 100 |
| ミッション欄 | x 100、大文字の上端 52、行の間隔 37 | 同じ |
| 文字の大きさ | 大文字の高さ 20（にじみを含む） | 本文 31、SPEED・ALT の見出し 24 |
| 線の太さ | 芯 2 | 2 |
| 色 | 芯が白に近い淡い緑。暗い背景で RGB 179,232,181 | `rgba(215, 255, 220, 0.8)` |

文字の大きさは撮って測って決めた。28 画素で撮ると GUN の行が 18 画素、録画は 20 だった。31 にして 20 になった。

周りに広がる光りは付けない。録画の線を暗い背景で横に切ると、芯は 2 画素で背景より約 100 明るい。両脇の 1〜2 画素は背景より 30 前後暗い。光りではなく縁取りに近く、動画の圧縮で強まった可能性がある。

## やめたもの

録画に無いので、次をやめた（ユーザーの決定）。

- 左下の G・AOA・THR の読み
- 右下の AGL
- 照準の右の DLZ の縦の帯

DLZ の計算（`src/sim/weapons/dlz.ts`）は残す。SHOOT を出す判定が使う。脚とフックの表示は、段 B2 で照準の下の状態の欄へ移すまで、レーダーの右（幅の 24%）に残す。

## 録画と合わないところ

兵装の一覧の下端が録画より 44 画素上にある。録画は特殊兵装の行を含めて 5 行、こちらは 4 行。特殊兵装は作らない（ユーザーの決定）ので、行の位置と間隔だけを合わせた。

SPEED と ALT の箱の外側に、増減の三角が出る（段 36）。録画には見当たらない。やめるかは、段 B2 でユーザーに諮る。

照準の十字・ロックの箱・矢印など、録画で測っていない部品には縮尺 `u = scale × 1.5` を掛けた。表示倍率 150% の全画面（CSS で 1280x720）で以前と同じ大きさになる。段 B3 で録画の値に置き換える。

## 確かめたこと

`tests/hud/layout.test.ts` が、1920x1080 で録画の外接矩形と各辺が画面の 1% 以内（横 19.2・縦 10.8 画素）にあることを見る。

公開ページと同じビルドを、Windows の Chrome（Intel Arc 140V）で 1920x1080 と 1280x720（倍率 1.5）の 2 通りに撮った。HUD のキャンバスだけを取り出して測ると、兵装の一覧の下端のほかは、どちらの大きさでも許容の内だった。

1600x789（倍率 1.5）・high で 20 秒測ると、60fps のまま品質は下がらなかった。GPU は 8.7 ms（変更前 10.1）、CPU は 8.0 ms（変更前 8.7）、うち HUD は 0.1 ms で変わらない。
