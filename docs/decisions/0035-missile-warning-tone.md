# 0035 ミサイル警告音を録画の持続音にする

2026-10-21 決定。Phase 10 の段 B10。録画（lesson 5）の警報の区間の音を測り、警告音を作り直した。音そのものは写さず、高さと揺れの周期だけを使って合成する。

## 録画で測ったこと

lesson 5 の 695〜730 秒を、16 kHz・1 チャンネルで切り出した。音は scratchpad に置き、リポジトリには入れていない。切り出しには、scratchpad の仮想環境に入れた imageio-ffmpeg 0.6.0（同梱の ffmpeg 7.0.2）を使った。記録は `~/.claude/plans/dogfight-ac7-ref/measure/b10_measure.txt`。

| 見たこと | 値 |
|---|---|
| 警報の区間（HUD が赤い 3 区間）に出る線 | 約 2,300・3,060・3,830・4,600 Hz。約 766 Hz の 3〜6 倍の倍音 |
| 線が続く長さ | 5.5〜5.8 秒。HUD が赤い時間（約 2.7 秒）より約 3 秒長い |
| 線の強さ | −46.3〜−48.1 dB で、区間の中でほぼ一定。途切れない持続音 |
| 線のすぐ下の弧 | 高さが一瞬下がって戻る揺れとみた。周期は、相関がいちばん高い窓で 150 ms |

字幕は「ミサイルが接近すると音の間隔が短くなる」。1 秒ごとの自己相関は相関 0.11〜0.53 と低く、周期は 50〜524 ms にばらついた。ナレーションと効果音が重なるためで、間隔が縮むかは数値で確かめられなかった。

## 決めたこと

| 項目 | 段 B9 まで | 段 B10 | 出典 |
|---|---|---|---|
| 音の形 | 880 Hz の矩形波 0.12 秒を 0.5 秒おきに鳴らす断続音 | 766 Hz ののこぎり波の持続音を 2 本重ね、1 本の高さを 0〜−57 セント揺らす | 録画 |
| 揺れの周期 | なし | 着弾まで 6 秒以上で 150 ms、1 秒以内で 60 ms、間は一様に縮める | 150 ms は録画、60 ms は推測（ユーザーの選択） |
| 鳴る長さ | 追われているあいだ | 同じ。HUD の MISSILE ALERT と合わせる | 録画は約 3 秒長いが、HUD に合わせた（ユーザーの決定） |

揺れの深さ 57 セントは、録画の弧が 4,600 Hz の線の下 約 150 Hz（約 3.3%）にあったことから決めた。2 本の大きさ（0.11 と 0.08）は、前の断続音と耳で並ぶ程度にした推測の値。

着弾までの秒は sim の `MissileThreat.timeToImpact` を使う。音の層には `AudioView.timeToImpact` で渡す。

## 確かめたこと

- vitest の `tests/audio/warningTone.test.ts`。高さが録画の倍音の ±2% に入ること、周期が 150 ms から 60 ms へ一様に縮むこと。
- E2E の「警告音は 766 Hz の倍音を持つ持続音」。`?audioprobe=1` で 1 秒書き出し、0.1〜0.9 秒を測る。3〜6 倍の高さの強さはその ±6% より 48〜58 dB 強く（線は 10 dB）、20 ms ごとの大きさの最小と平均の比は 0.73（線は 0.6）。
- 歯型を 3 件足した。`warning-tone-old`（880 Hz に戻す）、`warble-near-slow`（直前の周期を 90 ms に）、`warble-never-shrinks`（周期を縮めない）。
- 着弾までの秒で周期が縮むことは純関数で見ている。書き出した音から周期を測る検査は無い。2 本の音の干渉で強弱が出て、周期だけを取り出しにくいため。
