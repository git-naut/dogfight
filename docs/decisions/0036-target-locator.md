# 0036 画面の外の相手を指す印を録画のターゲットロケーターにする

2026-10-22 決定。Phase 10 の段 D8。ユーザーの依頼「敵機の位置を表示している矢印の HUD も、録画の透明な三角錐（距離によって鋭角になる）のようにしたい」を受けた。

## 録画で見たこと

lesson 5 の字幕「ターゲットロケーター　視野外にいる敵機を教えてくれる」（652 秒、コマ 19500〜19640）と、その後のコマ 19660〜19730 を 1.5 倍に拡大して読んだ。

| 項目 | 録画 | 段 35 から段 D7 まで |
|---|---|---|
| 形 | 線だけの細長い三角錐。先端・底の左右の角・底の真ん中のくぼみを結び、先端からくぼみへ稜線 | 塗りつぶしの小さな三角（長さ 12・幅 14） |
| 長さ | 約 113〜120 画素 | 12 |
| 底の幅 | 約 17〜30 画素。コマごとに変わる | 14 |
| 置く場所 | 底が画面の中心から 約 80〜90 画素、先端は 約 200 画素 | 中心から短い辺の 40%（1080 で 約 430 画素） |
| 色 | 主の緑 | 敵はピンク、味方は主の色 |
| 名前 | 右に機種名（F-16C） | なし |

## 決めたこと

| 項目 | 値 | 出典 |
|---|---|---|
| 形 | 線だけの三角錐。くぼみの深さ 14 画素 | 録画 |
| 長さ | 115 画素 | 録画 |
| 底を置く場所 | 画面の中心から 85 画素 | 録画 |
| 底の幅 | 相手が 1 km 以内で 30、8 km 以上で 14、間は一様に細くする | 幅の範囲は録画、距離の範囲は推測（ユーザーの選択） |
| 色と名前 | 主の緑の線だけ、機種名を右に。左を指すときは左に | 録画（ユーザーの選択） |

画素は 1080 の画面での値で、HUD の縮尺に比例する。寸法と形は `src/hud/arrow.ts` の純関数 `locatorWidth`・`locatorShape`。

真後ろの相手を指す印は、下向きに伸びて自機の胴体の背に重なる。段 35 は、塗りつぶしの三角がノズルの間で炎とまぎれたので、短い辺の 40% まで離していた。録画には真後ろを指す場面が写っていない。線だけの印なので機体が透けて見えるとして、どの向きも中心の近くに置いた（ユーザーの決定）。機種名は機体に重なって読みにくい。

## 確かめたこと

- vitest の `tests/hud/arrow.test.ts` に 3 件足した。幅が距離で一様に細くなること、底と先端の位置、縮尺と向き。
- 歯型を 2 件足した。`locator-not-sharper`（遠くても細くしない）と `locator-base-near-center`（底を中心から 40 画素に置く）。
- 実機の GPU で、敵が真後ろの場面（`enemy-missile` の f600）と後方 8 km の場面（`mission-kill` の f600・f1500）を撮り、録画のコマ 19700 と並べた。
