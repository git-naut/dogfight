# 0037 実録音の効果音を取り込む

2026-10-22 決定。Phase 10 の段 B11a。音の刷新（B11）の最初の段として、Freesound の CC0 の実録音を取り込む道具を作った。音を鳴らす側（エンジン・機銃・ミサイル・通過）は B11b〜B11d で作る。

## 元のファイル

ユーザーが 2026-10-05 にダウンロードへ落とした 10 件のうち 7 件を使う。各ページの長さとファイルの長さが 10 ms 以内で一致し、ライセンスは 2026-10-22 にページの原文で確かめ直した。出典は `assets/CREDITS.md` の効果音の表。

機関砲は 611449（M61A2）を使う。ページに出所の記載が無く、ゲームなどから抜いた音の恐れを否定できないが、ユーザーの選択で使う。CC BY 4.0 の 349713（CF-18 のアフターバーナー）は入れず、CC0 だけで始める（ユーザーの選択）。

## 切り出した区間

大きさと音色（周波数の重心）を時間ごとに測って、落ち着いた区間を選んだ。記録は `~/.claude/plans/dogfight-ac7-ref/measure/b11_sources.txt`。

| 書き出し | 元 | 区間 | 使い方 |
|---|---|---|---|
| engine-turbine | 205581 タービン | 30〜40 秒 | ループ |
| engine-idle | 187734 F-22 のアイドル | 4〜14 秒 | ループ |
| engine-burner | 104883 アフターバーナー | 22〜30 秒 | ループ |
| burner-light | 162242 アフターバーナーの点火 | 8.5〜13 秒 | 1 回 |
| flyby | 135495 F-18 の通過 | 15〜35 秒 | 1 回 |
| gun-loop | 611449 M61A2 | 1.0〜2.9 秒 | ループ |
| gun-tail | 611449 M61A2 | 3.0〜4.5 秒 | 1 回（撃ち止めの余韻） |
| missile-launch | 162368 ヘルファイアの発射 | 0〜2.3 秒 | 1 回 |

## 作り方

`tools/audio-import.mjs` が、元のファイルを 48 kHz・1 チャンネルで読み、区間を切り出す。ループは区間の終わりのあとを頭へ等パワーで重ね（機銃 0.1 秒、ほか 0.25 秒）、継ぎ目の段差を消す。1 回鳴らす音は頭 5 ms と終わり 30 ms を薄める。大きさは、ループを RMS −18 dBFS、1 回の音をピーク −1 dBFS にそろえる。Opus 64 kbps で書き出し、ffmpeg で読み戻して長さと継ぎ目を測り、`public/audio/manifest.json` に残す。

ffmpeg は scratchpad の仮想環境に入れた imageio-ffmpeg 0.6.0（同梱の ffmpeg 7.0.2）を使った。CI には ffmpeg が無いので、書き出したファイルをコミットし、作り直すときは手元で流す。

機銃のループは、重ねを 0.05 秒にすると、読み戻した継ぎ目の比が 3.24 で線を越えた。1 発ごとに音が立ち上がるため。0.1 秒にして 1.19 になった。

## 確かめたこと

| 項目 | 値 | 合格の線 |
|---|---|---|
| 大きさの合計 | 434 KB | 1 MB 以内 |
| 読み戻した長さ | 8 本とも書き出す前と同じ | 5 ms 以内 |
| ループの継ぎ目の比（読み戻し） | タービン 0.81・アイドル 0.79・アフターバーナー 0.78・機銃 1.19 | 3 以内 |

継ぎ目の比は、末尾から頭へ飛ぶ差を、ふだんの隣り合うサンプルの差（中央値）で割った値。

- vitest の `tests/tools/audioAssets.test.ts`。記録とファイルの大きさの一致、合計、長さ、継ぎ目を見る。
- E2E の「実録音の効果音をブラウザで読み戻せ、ループの継ぎ目に段差がない」。Chrome の `decodeAudioData` で読み戻し、長さと継ぎ目を見る。
- 試聴用の WAV を `C:\Windows\Temp\dg-pw\b11\` に置いた（ループは 3 回つなげた）。
