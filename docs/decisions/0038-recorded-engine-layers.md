# 0038 エンジン音を実録音の 3 層にする

2026-10-22 決定。Phase 10 の段 B11b。エンジン音を、合成音（ノイズのローパスと低いのこぎり波）から、ADR 0037 で取り込んだ実録音の 3 層に替えた。

## 決めたこと

| 層 | 録音 | 大きさ（スロットル t） | ほか |
|---|---|---|---|
| アイドル | engine-idle（F-22 のアイドル） | 0.1 + 0.45 ×（1 − smoothstep(0.1, 0.7, t)） | — |
| タービン | engine-turbine（ジェットのタービン） | 0.15 + 0.8 × smoothstep(0, 0.85, t) | 再生の速さ 0.85 → 1.15 倍 |
| アフターバーナー | engine-burner（轟音） | 0.8 × smoothstep(0.85, 1, t) | 0.85 は sim の `AUGMENTATION_THROTTLE` |
| 点火 | burner-light（1 回） | 0.5 | 0.85 を下から越えた瞬間。1 秒以内のくり返しは鳴らさない |

全体の大きさは 0.9 倍。値はどれも推測で、ユーザーが試聴して決める。純関数は `src/audio/engineMix.ts`。

最初はアイドルとタービンの幅を 0.55 ずつにした。スロットル 0.2 から 0.7 へ上げても大きさが 0.05 dB しか上がらなかった。アイドルを下げるぶんと、タービンを上げるぶんが打ち消し合っていた。幅を 0.45 と 0.8 に改めた。

## 読み込みと入れ替え

音のファイルは、音を作るとき（START）に読み始める。読み終わるまでは合成音で鳴らし、読めたら 0.5 秒かけて合成音を下げ、実録音を上げる。読めなかったときは合成音のまま鳴らす。音は無くても遊べるので、止めない。

## 確かめたこと

`?audioprobe=1` で、スロットル 0.2・0.7・1.0 のそれぞれを 1.5 秒書き出し、鳴り始めの 0.5 秒を除いて測った（2026-10-22）。

| t | 全体の大きさ | 音色の重心 | アフターバーナーの帯（200〜800 Hz） |
|---|---|---|---|
| 0.2 | −23.75 dBFS | 1,013 Hz | 40.5 dB |
| 0.7 | −20.13 dBFS | 2,171 Hz | 37.2 dB |
| 1.0 | −14.71 dBFS | 558 Hz | 53.8 dB |

合格の線は、大きさが段ごとに 2 dB 以上上がること、0.7 の重心が 0.2 より高いこと、1.0 のアフターバーナーの帯が 0.7 より 6 dB 以上強いこと。1.0 で重心が下がるのは、轟音の低い帯が重なるため。

- vitest の `tests/audio/engineMix.test.ts`（5 件）。
- E2E の「START のあとエンジンが実録音に切り替わる」と「エンジンの 3 層がスロットルで重なる」。
- 歯型を 2 件足した。`engine-mix-flat`（最初の幅に戻す）と `burner-always-on`（アフターバーナーが常に鳴る）。
