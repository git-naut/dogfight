# 0043 敵機にロックされたときの WARNING

2026-10-23 決定。Phase 10 を閉じる前の宿題の 2 つめ。録画の講座は「ロックオンされるとアラートが鳴る」と字幕で説明している。今のゲームには、ミサイルが飛んでくるあいだの MISSILE ALERT しか無かった。敵機の照準に入っていることを、ミサイルの前後にも知らせる。

## 録画の実測

lesson 5 の回避機動の区間（コマ 21160〜21500）を 2 コマおきに読み、音をスペクトログラムで見た。同じ場面が 3 回使われていて、観察できたのは実質 1 回分。

| 項目 | 値 | 出典 |
|---|---|---|
| 出る場面 | 敵のミサイルが過ぎ、MISSILE ALERT が消えた直後から。敵機は後ろに残っている | コマ 21432〜21482（編集の切れ目 21490 まで） |
| 位置 | MISSILE ALERT と同じ。画面の中心 x=960・y≈438 | 同上 |
| 形と色 | 枠つきの文字。暗い背景で (174,113,143) の淡いピンク | コマ 21236 |
| 点滅 | 6 コマ点いて 6 コマ消える（周期 0.4 秒） | コマ 21236〜21257 |
| HUD の色 | 緑のまま。MISSILE ALERT のときだけ全体が赤い | 同上 |
| 音 | WARNING に替わった 714.45 秒で持続音が止まり、MISSILE ALERT の 716.45 秒で戻る。そのあいだ音程のある線は見えない | 704〜718 秒の音 |

同じ区間の MISSILE ALERT は、2 コマおきに見ても毎回点いていた。段 B2 で lesson 4 を測った点滅（6 コマずつ）とは合わない。今のまま点滅させる（ユーザーの決定）。

## 決めたこと

| 項目 | 値 | 出典 |
|---|---|---|
| ロック | 敵機が自機を撃てる形（距離 1.5〜6 km・機首から 20 度以内・追尾か射撃の状態）にあり、弾が残っている | ユーザーの決定 |
| 上の欄の順 | MISSILE ALERT、WARNING、CAUTION。墜落したら WARNING と CAUTION は出さない | Claude の案（ユーザーが合格の条件として承認） |
| 見た目 | MISSILE ALERT と同じ位置・警告の色・点滅。HUD は赤くしない | 録画 |
| 点滅の起点 | WARNING が上の欄に出始めたフレーム。ロックが始まった瞬間か、ロックしたままミサイル警告が消えた瞬間 | MISSILE ALERT と同じ考え方 |
| 音 | 鳴らさない | 録画（ユーザーの決定） |

この作品の敵機はロックの状態を持たず、撃てる形になればその場で撃つ。そのため WARNING が単独で出るのは次の 2 つ。

- 撃った直後の約 0.2 秒。撃ったばかりのミサイルは、自機に近づく速さが判定の下限を超えるまで警告に数えられない。
- 弾を残したまま 1 発目を外したあと、次に撃てるまで（間隔 6 秒）。録画の場面はこちら。

ロックの判定は `src/sim/ai/fighter.ts` の `lockingOn`。全機のまとめは `World.lockWarning`（型は `src/sim/weapons/warning.ts` の `LockWarning`）。HUD の文字は `src/hud/readout.ts` の `upperStatusText`。

点滅の起点は、最初はロックの始まりにしていた。台本 `lock-warning` の敵機はフレーム 1 からロックし続けるので、起点は 1 のままだった。これではミサイルを外したあとの WARNING の位相が、前のミサイルの長さで変わる。起点を、上の欄へ出始めた瞬間に直した。E2E で見つけた。

## 確かめたこと

- vitest の `tests/sim/lockWarning.test.ts`（11 件）。撃てる形で弾があればロックし、弾切れ・回避中・立て直し中・遠すぎ・機軸の外ではしない。撃ったあとの待ちのあいだも続く。WARNING の始まりはミサイル警告が消えた瞬間。自機が落ちたら消え、毎回同じ結果になる。
- vitest の `tests/hud/readout.test.ts` で上の欄の順。
- 台本 `lock-warning` を足した。後方 1,600 m の敵機が 3 発を積み、f300 のフレアで 1 発目を外す。f588 から 2 発目の f721 まで WARNING だけになる（1.1 秒）。
- E2E で、f600 に WARNING が点いて HUD が緑、f612 で消え、f636 でまた点き、f730 で MISSILE ALERT と赤に替わる。HUD の点滅の起点を外して壊すと落ちることを手で確かめた。
- 基準画像 `hud-lock-warning`（`lock-warning` の f600）を足して 47 枚。既存の 46 枚は 1 画素も動いていない。
- 歯型を 5 件足した。
