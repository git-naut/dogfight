# 0044 自前の空（Hillaire）の光の尺度

2026-10-26 決定。Phase 11 の段 S2a。空を takram（Bruneton）から、web-ocean の技法（Hillaire 2020 の LUT）へ移す前に、光の強さをどこに合わせるかを決めた。この段では隠しの口 `?sky=hillaire` の裏に置き、既定の絵は変えていない。2026-10-28 の段 S2b-2 で既定へ切り替え、takram を外した（ADR 0045）。実測の詳細は `docs/measuring.md` の「段 S2a」。

## 直達光は takram に合わせる

露出 6、ブルームの閾値、VFX の色は、takram の光の尺度で決めてある。直達光がずれると、それらを全部測り直すことになる。takram の輝度の換算（太陽用）をそのまま使い、Hillaire の透過率に掛けた。6 時刻とも takram と 0.2% 以内。許容は 3%。

## 天空光は物理の値を採る

今の takram の天空光は、近似の無い正解（モンテカルロ法の光線追跡）より昼に 1.24〜1.61 倍明るかった。Hillaire は正解と 3% 前後で一致した。ユーザーが物理の値を選んだ。日陰と空は、昼に 25〜40% 暗くなる。夕方はほとんど変わらない。

takram が明るく出る原因は特定していない。以前の段の記録では、node の実行時 LUT が同梱の EXR より 1.7〜2.1 倍明るかった。向きは合うが、確かめてはいない。

## 天空光の関門は太陽高度で分ける

関門は、太陽高度 25 度以上で正解と 3% 以内、25 度未満で 5% 以内。Hillaire は低い太陽で青を約 4% 低く出し（17 時 3.3%、18.3 時 4.6%）、LUT の刻みを細かくしても残った。多重散乱の近似（2 回目以降の散乱を向きに依らないものとして無限次まで足す）に固有のものと見ている（推測）。

25 度の境は、結果を見たあとで引いた線。3% を全時刻に掛けると 2 時刻が落ちる。近似を改める調査は採らなかった。成果を見込めず、段も大きく延びるため。

## GPU と CPU の突き合わせの許容

LUT は、GPU の読み戻しと CPU 参照の差を「各色の LUT の最大値に対する割合」で測り、2e-3 以内とする。最初は画素ごとの相対 1e-3 で合意していた。多重散乱は最大値に対して赤 1.4e-3、太陽が地平線のすぐ下の帯（値が 1e-7〜3.6e-4）では画素ごとに 7.6e-3 ずれた。テクスチャの補間の精度は原因でなかった（自前の補間でも同じ値）。64 方向 × 20 歩を 32 ビットで足し上げる精度と見ている（推測）。光の強さとしての影響は小さい。LUT を引いて半球で足した天空光の差は 3.5e-4 で、こちらは相対 1e-3 で縛る。

## 定数

散乱の定数は takram（Bruneton の既定）にそろえた。上端 6,420 km、ミーの非対称 0.8、地面の反射率 0.1、ミーの減衰 4.44e-3。web-ocean（Hillaire 2020 の値）との差は天空光で 2〜3%。今の絵との連続を取った。散乱の式（積分の刻み、LUT の写し方、多重散乱の近似）は web-ocean のまま。

## 月

自前の空は月を描かない。基準画像では `aircraft-vortex` の 1 枚に薄い三日月（53 画素）が写っていたが、web-ocean に月は無く、描かないことにした（ユーザーの決定）。
