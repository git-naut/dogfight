# 実機で確かめる

Phase 7 の段 14。**数値では測れない領域**をここで決める。機械で測れるものは既に測ってあるので、ここに残っているのは「遊んでみないと分からない」項目だけ。

公開先は `https://git-naut.github.io/dogfight/`。`main` へ push すると GitHub Actions が公開する。手元で見るなら `npm run dev`。

## 直す値は 4 つ

| 値 | いま | 決め方 | 出どころ |
|---|---|---|---|
| 機銃の携行弾数 | 1,800 発 | 5 機落として余る量に | `src/sim/weapons/gun.ts` の `MAGAZINE` |
| ミサイルの数 | 8 発 | 同上 | `src/sim/combat.ts` の `MISSILE_COUNT` |
| 制限時間 | 300 秒 | 慣れた人が 1〜2 割余らせる長さに | `src/sim/scripts.ts` の `missionSeconds` |
| シェーダの事前コンパイル | SwiftShader で 6.6 秒 | 実機の GPU での実測値 | `hook.compileMs` |

**どれも推定で置いてある。**根拠は各所の注記に書いた。1,800 発は 1 対 1 の実測（545 発で 1 機）から 5 機ぶんを外挿した値で、実戦の消費は測れていない。

**測定用の自動操縦では決められない。**8 機戦で撃墜 0、45 秒で自滅する（`tests/sim/mission.test.ts`）。空母の距離を 2,000 から 16,000 まで振っても、どれも 5 機とも残したまま落とされる。

## 遊ぶ手順

`?script=mission-01` で開く。既定の台本なので指定しなくてもよい。

1. タイトルの START を押す
2. 甲板でスロットル（Shift）を開けると射出される
3. 射出の 2.4 秒が終わったら機首を引いて上昇する
4. 敵 5 機と戦う（制限時間 300 秒）
5. 決着したらリザルトが出る。R でやり直す

`Escape` でポーズ。ポーズから設定を開ける。

## 見るところ

甲板から射出されて空戦に入る流れは成立しているか。射出直後に沈むのは実機と同じだが、海へ落ちるほどなら機首上げの角度（`LAUNCH_PITCH`、いま 10 度）を見直す。

降着装置は出ているか。離陸後に引き込まれるか。対地 80 m で切り替わる。射出の直後に消えるなら閾値が低すぎる。

5 機を落とし切れるか。制限時間は妥当か。残り時間が半分以上余るなら短くする。足りないなら延ばす。弾が余りすぎるなら減らす。

スタンダードとエキスパートで手触りは変わるか。設定画面の「操作」で切り替える。スタンダードはロールが 0.7 倍になり、入力がないとき水平へ戻り、地面が近づくと引き起こす。

音は邪魔になっていないか。機銃・爆発・ミサイル発射・警告・エンジンの 5 つ。音量は設定画面から。うるさければ個々のゲイン（`src/audio/synth.ts`）を下げる。

リザルトの数字は合っているか。撃墜数、自滅の内訳、経過時間、命中率、消費ミサイル。

起動時間は待てる長さか。シェーダを 4 段ぶん先に作っている。長すぎるなら `?precompile=0` と比べて、ゲーム中のスパイクとどちらを取るか決める。

## 実機の値を記録する

`?debug=1` で計器が出る。GPU フレーム時間、プリセット、ドローコール、三角形数。

シェーダの事前コンパイルにかかった時間は `window.__dogfight.compileMs` で読める。ブラウザのコンソールから。

```js
const h = window.__dogfight
console.log(`起動時のシェーダ ${h.compileMs.toFixed(0)} ms / プログラム ${h.programs} 個`)
```

## 直したあとにやること

値を変えたら `npm test` と `npx playwright test` を通す。基準画像は `node /home/naut8/tools/dogfight-probes/exact.mjs` で画素単位に照合する。

制限時間を変えると `hud-mission` と `hud-mission-failed` の絵が変わる。弾薬を変えると HUD の残弾表示が変わる（`GUN 1800` の桁数）。**どちらも基準画像を撮り直す。**`--update-snapshots=all` を明示すること。値なしでは preset が `changed` で、テストが通る限り書き換わらない。
