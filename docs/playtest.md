# 実機で確かめる

Phase 7 の段 14。**数値では測れない領域**をここで決めた。機械で測れるものは先に測ってあるので、残っていたのは「遊んでみないと分からない」項目だけ。

公開先は `https://git-naut.github.io/dogfight/`。`main` へ push すると GitHub Actions が公開する。手元で見るなら `npm run dev`。

## 2026-08-31 の結果

4 つとも置いた値のままでよいと判断した。**数値の裏付けではなく、通しで遊んだ手ごたえによる確認。**

| 値 | 置いた値 | 結果 | 出どころ |
|---|---|---|---|
| 機銃の携行弾数 | 1,800 発 | このまま | `src/sim/weapons/gun.ts` の `MAGAZINE` |
| ミサイルの数 | 8 発 | このまま | `src/sim/combat.ts` の `MISSILE_COUNT` |
| 制限時間 | 300 秒 | このまま | `src/sim/scripts.ts` の `missionSeconds` |
| 起動の待ち時間 | シェーダを 4 段ぶん先に作る | 余裕の範囲 | `hook.compileMs` で読める |

**測定用の自動操縦では決められなかった。**8 機戦で撃墜 0、45 秒で自滅する（`tests/sim/mission.test.ts`）。空母の距離を 2,000 から 16,000 まで振っても、どれも 5 機とも残したまま落とされる。

人が遊ぶ以外に方法がなかった。

1,800 発という数は 1 対 1 の実測（545 発で 1 機）から 5 機ぶんを外挿したもの。実戦の消費は測っていないが、遊んで足りることは分かった。

## 遊ぶ手順

`?script=mission-01` で開く。既定の台本なので指定しなくてもよい。

1. タイトルの START を押す
2. 甲板でスロットル（Shift）を開けると射出される
3. 射出の 2.4 秒が終わったら機首を引いて上昇する
4. 敵 5 機と戦う（制限時間 300 秒）
5. 決着したらリザルトが出る。R でやり直す

`Escape` でポーズ。ポーズから設定を開ける。

## 次に遊ぶとき見るところ

値を変えたあとや、あとから手を入れたときに見直す観点。

甲板から射出されて空戦に入る流れ。射出直後に沈むのは実機と同じだが、海へ落ちるほどなら機首上げの角度（`LAUNCH_PITCH`、いま 10 度）を見直す。

降着装置。対地 80 m で切り替わる。射出の直後に消えるなら閾値が低すぎる。

5 機を落とし切れるか、制限時間は足りるか。残り時間が半分以上余るなら短くする。足りないなら延ばす。弾が余りすぎるなら減らす。

スタンダードとエキスパートの手触りの差。設定画面の「操作」で切り替える。スタンダードはロールが 0.7 倍になり、入力がないとき水平へ戻り、地面が近づくと引き起こす。

音の大きさ。機銃・爆発・ミサイル発射・警告・エンジンの 5 つ。音量は設定画面から。うるさければ個々のゲイン（`src/audio/synth.ts`）を下げる。

リザルトの数字。撃墜数、自滅の内訳、経過時間、命中率、消費ミサイル。

起動の待ち時間。シェーダを 4 段ぶん先に作っている。長すぎるなら `?precompile=0` と比べて、ゲーム中のスパイクとどちらを取るか決める。

## 実機の値を読む

`?debug=1` で計器が出る。GPU フレーム時間、プリセット、ドローコール、三角形数。

シェーダの事前コンパイルにかかった時間は `window.__dogfight.compileMs` で読める。ブラウザのコンソールから。

```js
const h = window.__dogfight
console.log(`起動時のシェーダ ${h.compileMs.toFixed(0)} ms / プログラム ${h.programs} 個`)
```

## 次に値を変えるときは

値を変えたら `npm test` と `npx playwright test` を通す。基準画像は `node /home/naut8/tools/dogfight-probes/exact.mjs` で画素単位に照合する。

制限時間を変えると `hud-mission` と `hud-mission-failed` の絵が変わる。弾薬を変えると HUD の残弾表示が変わる（`GUN 1800` の桁数）。**どちらも基準画像を撮り直す。**`--update-snapshots=all` を明示すること。値なしでは preset が `changed` で、テストが通る限り書き換わらない。
